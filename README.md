
# UIKit Implementation: DevGroves Recreation

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

##  About UIKit 

[UIKit](https://getuikit.com) is a lightweight, modular front-end framework for developing fast and powerful web interfaces. This project demonstrates its core capabilities by recreating the DevGroves website.

Responsive Navbar using uk-navbar with mobile toggle

Card Components for portfolio items with hover animations

Custom Theme via SCSS variables

Lightbox Gallery for project showcases

Form Validation in contact section
